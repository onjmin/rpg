# 蓄音キリコの大冒険

おんJ（おーぷん2ちゃんねる なんでも実況J）発の UTAU 音源「蓄音キリコ」が主人公の、スマホでサクッと遊べる RPG です。

- 遊ぶ: https://onjmin.github.io/rpg/
- 操作: 画面の十字キーと A/B（B でメニュー）、または行きたい場所・話したい人をタップ。PC はキーボード（矢印/WASD・Z/Enter・X/Esc）。
- 右上の 🔊 で BGM・効果音をまとめてミュートできます。
- セリフの読み上げ（ボイス）は既定で OFF です。メニューの「せってい」→「ボイス」で ON にできます（初回に約45MBのデータを取得します）。
- 公開サイトでは、アクセス解析のために Google アナリティクスを使っています（Cookie を使います。個人を特定する情報は集めません）。

## 立ち絵の差し替え

キリコ・ロゼ・フェリス・テト・足立レイの5人は、描き下ろしの立ち絵が入っています（表情差分なし・1枚絵）。
差し替えるときは、透過 PNG を次の名前で `public/portraits/` に置けば、そのまま表示されます。ファイルが無いキャラはダミー（キャラ色のシルエット）になります。

| キャラ | ファイル | ふだんの立ち位置 |
|---|---|---|
| キリコ | `public/portraits/kiriko.png` | 左 |
| ロゼ | `public/portraits/roze.png` | 右 |
| テト | `public/portraits/teto.png` | 右 |
| フェリス | `public/portraits/feris.png` | 右 |
| 足立レイ | `public/portraits/rei.png` | 右 |

**全員「右向き」（画面の右側を見る向き）で描いてください。** あとは自動で調整します。

- 向き: 右側に立つときは自動で左右反転して、画面の中央を向きます（左右非対称の髪型や文字も反転します）。
- 大きさ・位置: 透明な余白は自動で切り詰め、頭のてっぺんから足もとまでの高さがどのキャラも同じになるように拡大・縮小します。頭の位置も絵から測って、枠の中央・同じ高さにそろえます（アホ毛や耳の先は頭の高さに数えません）。キャンバスの大きさ・余白・ポーズはバラバラで構いません（横に広がる髪や腕は、外側は画面の端まで出し、内側は2人のあいだの真ん中でぼかして消します）。そろえるのは全身の高さなので、頭の大きい（2頭身寄りの）絵は頭が大きめに見えます（フェリスは `scale: 0.9` で小さくしています）。**全身絵で描いてください**。会話では上から約6割（頭〜腰）を切り出して見せます（`src/data/cast.ts` の `portrait.crop` でキャラごとに変更可。1 で全身）。自動の結果がずれるときだけ、`portrait` の `scale`（大きさの倍率）・`offsetX` / `offsetY`（全身の高さに対する割合で、右・下へずらす）で手直しできます。
- 立ち位置: ふだんの側がほかの話し手でふさがっているとき（ロゼとテトが話す場面など）は、空いている側へ自動で回ります。

反転させたくないキャラは、左向きで描いて `src/data/cast.ts` の `portrait` に `facing: "left"` を足してください（右側に立つときはそのまま、左側に立つときに反転します）。ほかのキャラに立ち絵を足すのも同じ場所です。

## 開発

```bash
pnpm install
pnpm dev
```

- `pnpm build` … 型チェックして `build/` に出力（`GITHUB_PAGES=true` で `/rpg/` 配下向け）
- `pnpm lint` … Biome
- `pnpm validate` … ゲームデータの検証（マップの形・ワープ先・話し手・戦闘グループ・セリフの長さなど。イベントを空の Story で走らせて調べる）
- `pnpm balance` … 戦闘バランスのシミュレーター（`ui/battle.ts` の計算を写して、本物のデータでオート戦を何千回も回す）。雑魚1戦で減る HP・全滅までの戦闘数・1レベルに何戦と、ボスの目安のレベル前後の勝率を出す。敵の数値は `BAL_TWEAK='{"zonj":{"atk":20}}'` で試しに上書きできる
- `pnpm loudness` … 効果音の大きさを測り直す（下の「効果音の音量（ラウドネス）」）
- `node scripts/make-sprites.mjs` … 素材が無かったドット絵（ムッジェ・ボツキリコ・蓄音機・おんJマイナーズ）を作り直す
- 開発中は URL でタイトルを飛ばして好きな場所から始められます（`pnpm dev` のときだけ）:
  `http://localhost:5173/?map=town&x=11&y=16&flags={"p_tut":true}&party=kiriko,nanj&lv=5`
  - `&bench=nanj`（`,` で区切って複数）でその仲間を控えにして始めます。たたかう仲間が4人以上いると、古いセーブと同じく自動で控えに回ります。
  - `&items=memo_roze:1,rec_first:1` で持ちものを決め打ちします（数を省くと 1、`:0` で なくす）。次スレでの差分を試すときに。
  - 誕生スレ（`map=thread`）から始めるときは `"done:thread:opening":true` を flags に入れてください（入れないと序章が始まります）。
  - 管理人室（クリア後）: `?map=admin&x=5&y=8&dir=up&flags={"clear":true,"ending_seen":true,"res":1000}&party=kiriko,roze,feris,teto&bench=teto&lv=12`
- タイトルの「デバッグルーム」（`pnpm dev` のとき。公開版でも URL に `?debug` を付けると出る）から、各章のはじめ・1000レス目・クリア後へ、その場面までのフラグ・仲間・レベルをそろえて飛べます（`src/data/maps/debug.ts`）。レベルは飛ぶ前に目安から上げ下げできます。どうぐ補充の人もいます。デバッグルームから始めた状態は記録しません（本物のセーブを上書きしない）。
- main に push すると GitHub Actions（`.github/workflows/gh-pages.yml`）がビルドして GitHub Pages に公開します（Settings → Pages の Source は「GitHub Actions」）。

### 構成

- `src/engine/` … エンジン（画面・入力・マップ・イベント実行・音・セーブ）
- `src/ui/` … メッセージ窓・立ち絵・メニュー・戦闘・タイトル・エンディング
- `src/data/` … ゲームの中身（キャラ・マップ・シナリオ・敵・BGM・効果音）
  - マップとイベントは `src/data/maps/*.ts`。シナリオは `async (s) => { await s.say("kiriko", "……") }` の形で書きます（使える命令は `src/engine/defs.ts` の `Story`）。
  - マップチップは unj-reze と同じ同梱シート（`public/assets/rpg-reze/Base.png`・`field.png`、`public/assets/rpgen/map.png`）から切り出しています。
  - キャラ・敵の歩行グラと効果音は、unj-reze の GameMaker と同じく RPGEN（rpgen-search）の素材を id で直リンクしています。

### なかま・控え と うたの習得

- たたかって歩くのはキリコを入れて3人まで（`src/engine/party.ts` の `MAX_ACTIVE`）。ほかの仲間は「控え」で、隊列にも戦闘にも出ず、経験値も入りません（戦闘の経験値も `s.gainExp` も）。回復・どうぐ・会話やおでかけは控えもふくめた全員が対象です。
- 控えとの入れかえは、フィールドのメニュー「なかま」→「いれかえ」でいつでもできます（キリコは外せません）。
- 仲間のデータは `state.party` で、たたかう仲間（隊列の順・先頭がキリコ）のあとに控え（`bench: true` の印）が並びます。いれかえで入った仲間は、抜けた仲間の隊列の位置に入ります。シナリオでは `s.bench(id)`・`s.unbench(id)`・`s.join(id, { bench: true })` を使います。たたかう仲間が3人いるときに `s.join` すると、控えに入れて知らせます（シナリオでは先に `s.bench` で誰かを下げる）。
- 古いセーブ（たたかう仲間が4人）は、読みこんだときに本編で控えに回る順（`src/data/index.ts` の `benchFirst`）で控えに回して知らせ、知らせのあとに保存しなおします（次に読んだとき また出ないように）。
- うた（戦闘の「うたう」）はレベルで覚えます。`src/data/cast.ts` の `battle.skills` に `{ id, lv }` で覚える順に書きます。加入したときは、そのレベル以下のうたを覚えています。レベルが上がると「キリコは　「〇〇」を　おぼえた！」が出ます。セリフで覚えたかどうかを見るときは `knows(s.state, "kiriko", "replay")`（`src/data/story.ts`）。

### 寄り道：おんJマイナーズ

`src/data/minors.ts`。おんJwiki の「一軍・二軍」まわりの顔文字キャラの寄り道。本編とは ゆるく からみます：話の進み（沈黙のあいだ・声がもどったあと・完走のあと）で1回だけの ひとことが出る、期間限定（ストーリーの区間。下の「期間限定と偶発」）の あいだは その区間の ひとことを言う（`limited`）、たたかう仲間が口をはさむ、会った子が終章のレスの洪水（>>995〜>>997）に書きこむ（`threadlog.ts` の `MINOR_POSTS`）、2回目からは その子の雑談（仲間の口出しつき）が1本ずつ出る（`chat`）。町の広場のおんちゃん（一軍）とにぃちぇ・スレ街道の北東のすみのおんすちゃん・スタジアムのヤヤポジとポジハメ・過去ログ倉庫の奥の間（B2 のあと）のンゴ姉とパン松。奥の間の はり紙で「一軍選抜総選挙」に1票入れられます（`vote`）。おんちゃん・ポジハメ・先住民（( ‘ｊ’ )「あ！今日土曜日ど！」）の歩行グラは RPGEN、ほかの5人は RPGEN に無かったので `scripts/make-sprites.mjs` で描いています。

RPGEN の歩行グラの検索（rpgen-search）は名前の**前方一致**です（「土曜日」では「あ！今日土曜日ど！」に当たらない）。見つからないときは、一覧をぜんぶ取ってから部分一致でさがすと確実です。

### 曜日連動（`src/data/weekday.ts`）

ゲームの中の日付は 2026-08-18（火曜日）のままです（先住民の「土曜日ど！」に やきうが「火曜日やぞ」と返す日）。それとは別に、遊んでいる端末の曜日が しみだしてくる所があります。

| 曜日 | 変わるところ |
|---|---|
| 毎日 | 勢い欄の2番目のスレタイ（B2 まで。火・土は もとの「土曜日ど！」）・おんちゃんの「今日のおんちゃん」 |
| 日 | にぃちぇ「あ！今日　日曜日だニィ！」 |
| 月 | スタジアムの観客（左上）「ほんまは　試合　ない日やで」 |
| 土 | にぃちぇ「あした　日曜日だニィ！」・先住民の「土曜日ど！」に やきうが言いかけて やめる |

現実の時間とつなぐのは**曜日の区切りまで**です。日付・月・季節（正月・ハロウィン・クリスマスなど）や誕生日の日付では変えません。

開発中は URL に `&wday=0`〜`6`（0 が日曜）を足すと曜日を決め打ちできます（`pnpm dev` のときだけ）。`pnpm validate` は その日の曜日しか通らないので、曜日の文を足したら 7曜日ぶん確かめてください（`Date.prototype.getDay` を差しかえて `scripts/validate.mjs` を走らせる、など）。

### 期間限定と偶発

いつでも起きるわけではない出来事は、次の2種類で作ります。

- **期間限定（ストーリー区間）** … ストーリーが その区間に いる あいだは ずっと起きて、区間を過ぎたら もう起きません。確率は使いません。区間は `src/data/story.ts` の `section`（`SECTIONS`。蓄音機の「いまの目的」と同じ区切り。完走のあとは `after`）。おんJマイナーズの期間限定の ひとこと（`minors.ts` の `*_LIMITED`）は、`pnpm validate` が区間ごとに走らせ、その区間に その子が いるか（`when`）と、話しかけに行けない区間（`LIMITED_UNREACHABLE`）に置いていないかも調べます。にぃちぇの土日の ひとことのように、曜日の文が先に出ても、期間限定は そのあとに言います。
- **偶発** … ストーリーとは関係なく、回数や確率で 起きたり 起きなかったりします。

現実の日付で起きる出来事は作りません（上の「曜日連動」）。

### 縛り（ふつうは しない 遊び方）

仕様では できるが ふつうは しない 遊び方で完走すると、エンディングで仲間が気づき、まとめカードの `>>998` に残ります（`src/data/threadlog.ts` の `shibari`）。

| 縛り | 見分け方 | 気づく人 |
|---|---|---|
| どうぐ縛り | 仲間が どうぐを1回も使っていない（`play_item`） | テト |
| うた縛り | 仲間が うたを1回も歌っていない（`play_song`） | ロゼ |
| 低レベル | ボツキリコに勝ったときの キリコが Lv8 以下（`f2_lv`） | やきう |
| キリコひとり | ボツキリコと ひとりで たたかった（`f2_solo`） | フェリス |

2つ以上なら スレの住民（J民C）も気づきます。`play_item`・`play_song` は戦闘とメニューで数えます（`engine/party.ts` の `countPlay`）。このしくみより前のセーブは数えていないので、`play_track`（はじめからの記録にだけ立つ）が無ければ 縛りとは みなしません。

### クリア後・次スレ（Part2）

- **テストサーバー**（`src/data/maps/exserver.ts`）… 管理人室のサーバーラックから入ります。歴代ボスの連戦（通し9戦・腕だめし・章のボス・終章・管理人）。あいだの回復は無く、全部たおすとタイムが `ex_<コース>` に残ります。本編のフラグは いじりません。
- **過去ログの発掘**（`src/data/digs.ts`）… 過去ログ倉庫の くずれかけた棚（`b`）4か所。`>>1` が欠けたログを読んで当てるパズルで、4つそろうと レコード「過去ログの声」。
- **次スレ**（`src/engine/newgame.ts`）… 完走したきろくがあると、タイトルに「次スレを　立てる」が出ます。物語の上では 同じ夜への 時間遡行です（キリコは 同じ キリコで、前の周を 覚えていない。覚えているのは 先輩と、カバンの中の品だけ）。引き継ぐのは 仲間のレベル（`p2_lv_<id>`。加入時に `join` が見ます）・なかよし度・見た会話・発掘・テストサーバーの記録・大事なもの。話の進みは まっさらに戻り、敵は `p2_n` に応じて強くなります（2周目 1.6倍、3周目 2.2倍）。フラグを足すときは `p2_` で始めると `validate` の「フラグの約束」から外れます（ただし持ち越しはしません）。スレをまたいで覚えておくフラグは `keep_` で始めます（`newgame.ts` の `CARRY_PREFIX`）。

### 裏シナリオ：過疎板探検（避難J）

本編が もう1本 ある 大きさの 隠しシナリオ。共通部品と 全体の 流れは `src/data/kaso.ts`。案内は しない（隠し）。
元ネタは おんJwiki の「過疎板探検」（約900の専門板の ほとんどが 無人。「最後にレスされたのが1000日前」。「人が増えると信じてレスし続けた開拓者」）と、おんJ の「1ヶ月間過疎板巡りしてきたワイが良スレだと思ったものを紹介していく」スレ（2018年）。4つの 板は どれも おーぷんに 実在する 板で、そこで 実際に つづいている スレを 勢い欄に 出す（スレの 中身は 創作しない。bot・残像・保守の 貼り紙は 創作）。

- **入口**：過去ログ倉庫の 北東の 空き部屋の 階段（(19,5)）。避難Jの ログを 掘っていないと（`dig_hinan`）まっくらで 下りられない。終章の サーバーの底の となりの ラック（`rack_other`）からも 入れる。倉庫の ヒナリーが「北東の 階段から ほかの板の 底を 通る」と 手がかりを 言う。
- **過疎板の底**（`maps/kaso.ts`）：おーぷんの ほかの板の サーバー室。モニター 6列×3段（`MONITORS`）。板を ひとつ 終えるたび その板の モニターが 点き、ヒナリー（研究中）が 避難Jの モニターの 位置の 手がかりを ひとつ 発表する（同じ段・同じ列・右上）。当てても 実験板で 回線（`sen_line`）を つなぐまでは 行けない。回線の あとの 外れは「しずけさ」の 戦い。
- **ヒナリーの 研究**：「蓄音キリコさんの レスを 数えています」「……数が、合いません」「足りないのは 4件」。板ごとに **沈んだレス**（大事なもの `sunk_145`・`sunk_130`・`sunk_329`・`sunk_111`。`data/kaso.ts` の `SUNK`）を 1件ずつ 拾い、拾った 数（`sunkCount`）で 中間報告。拾う 場面は 毎回 `s.has` を 見て、持っていれば「もう ひろってある」（`sunkHad`・`giveSunk`）。
- **板**（上の壁の 4つの 扉。難しさの 帯は 本編の 同じ 時期に そろえ、`pnpm balance` に 行が ある）：
  - **犬猫大好き板**（`maps/neko.ts`。第二章〜・Lv5〜6）：実在の「他の板の猫スレ紹介場」。ねこしか いなくなった 板。すずを つけた 板猫に ついていく（柵の すきま。`neko_step`）と 勢い欄に 着き、1000日 画像を はりつづけた「ぬこ画像bot」（中ボス）。大事なもの「板猫のすず」。猫が 落とした 紙が 沈んだレス >>145（8月17日。釣り）。
  - **料理板**（`maps/aisatsu.ts`。Lv6〜7）：実在の「料理雑談スレ」（よそから 書くと「お客さんだ」「いらっしゃい」が 返る 板）。のれんの「いらっしゃい」に 返事を すると 入れる。4人の 残像に 来た順（額の 日付）で あいさつを 返す 謎解き（`ais_n`）→ 1スレの >>1 当て → 常連bot（中ボス）。bot が 止まると 帳場（(15,10)）の 帳面が 読める：沈んだレス >>130（バラムツ → 再安価で 囲碁。却下の 理由は「食べたら あかん 魚」まで）。

### セリフの書き方

1行は全角22字・2行まで（`pnpm validate` が見ます）。そのうえで、**説明せず、行間を読ませる**方を選びます。

- **設定を読み上げない。** 生まれた年・身長・誕生日・おんJの用語は、なかよし度で開く**プロフィール頁**（`src/data/bonds/`）が持っています。会話はその場に要る分だけにして、残りは頁にまかせます。
- **気持ちに名前をつけない。** 「うれしい」「さびしい」と言わせる代わりに、動作・持ち物・はぐらかしで見せます。相手のことなら言ってよい（「先輩、ちょっと　うれしそうンゴ」）。
- **主題を言わせない。** 話のキモを一行にまとめた台詞は切ります。まわりの出来事が言えば足ります。
- **「だから」「つまり」でつながない。** 理由を足した瞬間に説明になります。黙って次の行へ。
- **語順を変える。** 同じ言葉でも、気持ちの語をうしろに置くと理屈から感情になります（「これが、うまいんだな」→「うまいんだな、これが」）。
- **口ではなくナレーションに。** `s.narrate` の一行（手の甲をならべる・羽をひろげる・蓄音機をまわす）は、説明台詞3行より強いです。
- **その人らしい逃げ方をさせる。** テトは「べ、別に」、やきうは茶化し、ロゼは「常識アル」。本心はそのうしろに置きます。

### 効果音の音量（ラウドネス）

効果音はいろいろな素材の寄せ集めで、そのままでは大きさがバラバラ（20 dB 近くちがう）なので、測った大きさ（LUFS）から1音ずつ音量を補正しています。目標と測り方は `src/data/loudness.ts` の先頭にまとめてあります。

- 効果音は区分（`ui` / `field` / `battle` / `impact` / `jingle`）ごとに目標の大きさがあります。既定の音量設定で、BGM（-23 LUFS）を基準に UI の音は小さめ、戦闘の音は少し大きめです。
- 効果音を足したり差し替えたりしたら、`src/data/sfx.ts` の合う区分に書いて `pnpm loudness` を実行してください。RPGEN から mp3 を取ってきて（`node_modules/.cache/loudness/` に保存）ffmpeg で測り、`src/data/loudness.ts` の `SE_LOUDNESS` を書き換えます。ffmpeg と ffprobe が要ります。測るまでの音は、前と同じ大きさ（既定で 0.3 倍）で鳴ります。
  - `--dry-run` で表を出すだけ、`--fresh` で mp3 を取り直します。
- BGM は曲ごとの MML の `#volume=` でそろえてあります（測った値と直し方は `src/data/bgm.ts`）。読み上げの声は、声ごとの大きさ（`VOICE_LUFS`）から音量を補正しています。

効果音が鳴ったあとは、その音の本体（エネルギーの 85 %）が鳴り終わるまで、文送り・選択肢の決定・戦闘の早送りとコマンドを止めます（連打で効果音が畳みかけないように。余韻までは待たず、長くても 1.2 秒・ジングルは 1.5 秒。メニューの音は待ちません）。この長さも `pnpm loudness` が測って `SE_LOUDNESS` に書きます。エンカウントは効果音が鳴り終わるまでフィールドを崩す演出でつなぎ、それから戦闘の画面と曲に移ります。
